# 장인기 개발자 포트폴리오

인사·급여 ERP 실무 약 3년, 직접 기획한 서비스를 만들어 운영하는 소프트웨어 개발자 장인기의 포트폴리오 사이트입니다.

**사이트**: https://iokl1004.github.io/janginki-portfolio/

## 소개

인사/급여/근태 모듈 중심의 ERP 구축과 유지보수 경험을 프로젝트별 케이스 스터디로 정리했습니다.
각 케이스는 문제, 접근, 결과 순서로 구성했고, 회사 프로젝트는 코드를 공개할 수 없어 설계와 처리 흐름 중심으로 설명합니다.
개인 프로젝트는 라이브 주소와 GitHub 저장소를 함께 연결했습니다.

## 주요 기능

- 회사 프로젝트 8개와 개인 프로젝트(책있나, memoir, 영화 정보 웹 서비스)의 케이스 스터디 상세 페이지
- 첫 화면에서 개인 프로젝트 화면을 넘겨 보는 슬라이드 (멈춤 버튼, 움직임 줄이기 설정 존중)
- 이메일·GitHub 주소 링크와 복사 버튼
- 강의와 독학으로 만든 실습 10개를 사이트·GitHub 링크와 함께 정리
- 기술을 실제 로고와 함께, 어느 프로젝트에서 썼는지 기준으로 정리 (AI 도구 포함)
- 시그니처 아이콘 "인기 스타"(Popular_Jang)를 파비콘과 상단 로고로 사용 (원본은 `brand/` 폴더)
- 라이트/다크 모드 (시스템 설정을 따르고 직접 전환 가능)
- 메뉴를 누르면 해당 섹션으로 부드럽게 이동, 오른쪽 바로가기 메뉴가 지금 섹션을 표시
- 상세 페이지에서 돌아왔을 때 보던 위치로 복원
- 휴대폰·태블릿 화면 대응

## 기술 스택

| 구분       | 사용 기술                    |
| ---------- | ---------------------------- |
| 프론트엔드 | React, TypeScript            |
| 빌드       | Vite                         |
| 스타일     | 순수 CSS (디자인 토큰, 그리드, 움직임) |
| 라우팅     | React Router (HashRouter)    |
| 배포       | GitHub Pages, GitHub Actions |

디자인은 Taste 스킬의 디자인 키트(`public/kit`)를 기반으로 합니다. 색, 서체, 그리드, 버튼, 상단 바, 마우스 반응 효과를 이 키트가 맡고, 페이지별로 필요한 부분만 `src/index.css`, `src/pages/home.css`, `src/pages/case.css`에서 더했습니다. 아이콘은 각 회사의 실제 로고 파일을 그대로 씁니다.

HashRouter를 쓴 이유는 GitHub Pages가 정적 호스팅이라 `/projects/...` 같은 주소에서 새로고침하면 404에러가 발생하기 때문입니다.

## 폴더 구조

```
public/kit/      디자인 키트 (CSS, 움직임 스크립트, 실제 로고 아이콘)
src/
├─ components/   공통 상단 바, 사이드 메뉴, 테마 버튼, 첫 화면 슬라이드, 복사 버튼
├─ data/         프로필, 프로젝트, 실습 프로젝트, 메뉴 데이터 (이 파일들만 고치면 내용이 바뀝니다)
├─ hooks/        스크롤 위치에 따른 활성 섹션 감지
├─ pages/        Home, CaseStudy와 각 페이지 CSS
└─ utils/        상세 페이지에서 돌아올 때 스크롤 위치 복원
```

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드
```

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 자동 배포합니다. (`.github/workflows/deploy.yml`)

## 개발 방식

이 사이트는 Claude(Anthropic)와 대화하며 개발했습니다.
프로젝트 내용과 성과는 제 경력기술서에 근거해 직접 확인하고 작성했고, 화면 구성과 기능 방향은 제가 정한 뒤 AI가 제안한 코드를 직접 실행하며 검토했습니다.
